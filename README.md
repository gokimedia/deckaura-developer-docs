# Deckaura Developer Documentation

Build tarot and spiritual-discovery experiences with Deckaura's open data, packages, and Model Context Protocol server.

## What is available

- A structured 78-card tarot dataset with upright, reversed, love, career, yes/no, element, zodiac, and guide fields
- CSV, JSON, and JSONL downloads
- JavaScript, TypeScript, Python, PHP, and Go integrations
- A local MCP server for AI assistants
- A permanent research archive with a DOI
